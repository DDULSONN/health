# 1:1 결제센터의 주문/연락처 상태

- 결제센터는 기존 주문 기록과 같은 주문으로 처리된 연락처 교환을 따로 표시한다. 결제 기록만 있거나 다른 주문·교환권으로 처리된 매칭은 해당 주문의 반영 완료로 표시하지 않는다.
- 대기 주문의 상태 확인 버튼은 기존 본인 주문 사전 확인을 GET으로만 요청한다. 승인·지급·결제 취소·번호 공개·새 결제창을 실행하지 않는다. 오래되거나 결제사 응답이 확실하지 않은 상태는 재결제를 유도하지 않는다.
- 기존 매칭 화면의 정상 구매 및 번호 확인 동선, 가격, 취소·차단·공개 규칙, 해외/국내 결제사 처리 함수는 변경하지 않는다.
- 결제사 정산·취소와 정기 대사, 미반영 건의 자동 복구는 별도 작업이다. 자동 처리 전 운영 권한과 결제사 승인 근거를 정비하고, 현재 스테이징에서만 상태별 검증을 진행한다.

합성 테스트: `node --require ./scripts/test-no-network.cjs --test ./scripts/check-contact-payment-order-state.cjs`. 브라우저는 빌드 CSS가 있는 환경에서 `node scripts/check-contact-payment-order-state-browser.cjs`.
