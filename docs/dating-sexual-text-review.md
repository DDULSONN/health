# 일반 검수: 성적 문구·부실 소개 확인

관리자 `일반 검수`의 문구 탐지 보강이다. 등록 차단, 자동 숨김·삭제·밴, 연락처 공개, 인증, 결제, 추천 로직에는 연결하지 않는다.

## 검사와 표시

- 기존 검수 대상(오픈카드, 유료카드, 1:1 카드 및 각 지원 내역)에 공통 적용한다.
- 작성자의 이름/닉네임, 직업, 소개, 강점, 이상형을 검사한다. 1:1 지원의 상대 이름·상대 ID, 인스타 계정 필드는 이 성적 문구 검사에서 제외한다.
- 성적 행위·만남 제안, 음란물·노골적 성적 표현은 `high`, 컵 사이즈 등 성적 신체 강조는 `medium`으로 관리자 확인을 요청한다. **정책 위반 확정이 아니다.**
- 성적 사유 하나만 있어도 기본 목록에 표시한다. 사유에 해당 필드명을 붙인다.
- 기존 앞 500자 절단을 2,000자로 늘려 현재 소개/이상형 입력 범위의 뒤쪽도 검사한다.
- 전각, 일부 구분기호·공백·제로폭 문자 우회도 정규화한다. 일반 운동/체형 표현, 성적 지향 자체, 즉각적인 거절 문구는 오탐을 줄인다. 규칙 기반이라 모든 은어·문맥을 완벽히 판별하지 못하며 관리자의 최종 판단이 필요하다.
- AI 검수를 추가로 실행해도 일반 검수의 더 높은 위험도와 사유가 사라지지 않는다.

## 부실 소개 확인

- 오픈카드는 `내 강점`이 소개 역할을 한다. 1:1 카드·지원 및 오픈/유료카드 지원은 `자기소개`를 검사한다. 유료카드는 자기소개가 비어 있으면 오픈카드에서 복사된 `내 강점`을 소개로 판단한다.
- 소개 역할 필드의 글자가 8자 미만이면 확인 대상으로 표시한다. 공백·기호·이모지·숫자·단독 자음/모음은 길이를 채우는 데 쓰지 않는다. 나이·직업·계정 ID·상대 정보·긴 이상형 문구를 소개 길이에 합치지 않는다.
- 인사말만 있는 글, `작성 예정`/`나중에 작성할게요` 등 임시 문구만 있는 글, 자음·숫자·기호만 있는 글, 4회 이상 반복된 짧은 문자/문구가 전체의 60% 이상인 글도 표시한다. 소개 외 강점·이상형에도 명백한 반복/임시 문구는 검사하지만 짧은 이상형 조건에는 8자 기준을 적용하지 않는다.
- `배려하며 잘 웃어요`처럼 간결하고 기준 길이를 충족하는 소개는 부실 소개로 표시하지 않는다. `QA 테스트 업무를 합니다`나 정상 소개 뒤의 웃음 표현은 테스트/반복이라는 이유만으로 잡지 않는다. 기존 전체 텍스트의 단순 `테스트` 부분일치·반복 문자 규칙을 이 항목별 검사로 교체한다.
- 한 가지 사유만 있어도 `medium`으로 기본 목록에 나온다. 공개 순서·추천 순서·등록 조건은 바꾸지 않는다. 의미를 완전히 이해하는 판정기가 아닌 관리자 검수 보조이므로 최종 판단은 관리자에게 있다.

## 기존 게시물

배포 후 대상을 선택해 **일반 검수**를 다시 실행한다. 기존 저장 결과를 소급 변경하거나 백그라운드로 전체 회원을 검사하지 않는다. 현재의 최신순/검사 건수 제한은 유지되므로 오래된 게시물은 대상 종류와 검사 건수를 조정해야 한다. `최근 검수 목록` 조회만으로 재검사되지는 않는다.

SQL 변경, 새로운 외부 서비스, 자동 메일 발송은 없다. 일반 검수는 AI 호출을 하지 않는다. DB 조회/기록과 앱 실행 비용까지 0이라는 의미는 아니다.

## 검증

`npm run check:dating-text-review`

실제 라우트를 오프라인 DB/AI 대역으로 실행한다. 여섯 대상의 탐지·저장·기본 목록 재조회, 500자 뒤 문구, 부실 소개·정상 예문·길이 경계, 유료카드 선택 입력, 재검수 시 결과 갱신, 관리자 권한, 기존 연락처 탐지, AI의 위험도 하향 방지를 검증한다. 회원·매칭 테이블 쓰기, 외부 통신, 메일 발송은 허용하지 않는다.
