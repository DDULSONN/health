# 지역·연령 보강 검증 — 2026-09-20

지역·연령 수정과 GitHub 반영 전 검증 기록. 운영 DB 수정·실제 결제·문자/메일 발송 없음.
지역 변경 상세는 [region-distance-hardening.md](./region-distance-hardening.md) 참고.

## 연령 기준과 한계

- 기존 서비스 안내(`DatingAdultNotice`, `dating-policy`)와 관리자 편집은 19세 이상이지만, 통합 작성은 현재 연도 - 18, 일부 서버 API는 1960~2010 고정값이었다.
- 공통 검증을 1960~현재 한국 연도 - 19로 통일했다. 2026년에는 최대 2007년생이다. 소수 반올림, 빈 값, 잘못된 문자열, 미래/기준 미달 연도는 거부한다.
- 이는 **자기 입력 출생연도 검증**이다. 생일/본인확인 기반의 정확한 만 나이 증명은 아니다. 기존 성인 자기 확인은 유지한다. 휴대폰 인증을 연령 인증으로 취급하지 않는다.
- 운영 활성 프로필 최신 1,572건 읽기 전용 점검에서 1,570건 통과, 2008년생·2010년생 각 1건 제외 대상 확인. 기존 회원 데이터/상태는 변경하지 않았다.
- 기존 수락 상태 3,206건 중 번호 교환 미승인·미취소 2,557건도 읽기 전용 확인: 카드 누락 0, 소유자 불일치 0, 연령 통과 2,553건, 부적격 연도가 포함된 4건. 패치 후 해당 4건의 새 번호 교환은 차단된다.

## 적용 범위

- 신규 작성, 본인 수정/복구, 관리자 편집/승인, 통합 작성/단독 작성 화면의 검증 통일.
- 추천 원본과 후보, 추가 후보, 찜 후보, 수동/관리자 선택에 공통 검증 적용. 가장 최신 카드가 부적격일 때 예전 성인 카드로 우회하지 않도록 최신 신원 확인 후 검사한다.
- 새로고침은 부적격이면 횟수 차감 전에 중단. 사진 상세 재조회 시에도 재검사.
- 기존 제안의 새 선택/수락, 신규 번호 교환, 관리자 승인, 일반 결제/플러스 번호 교환에 두 당사자의 카드 연령·소유자 검사.
- 예전 ready 주문도 결제 승인 요청 전에 재검사하고, 번호 공개 승인 전 다시 검사한다.
- 거절/취소/삭제 및 기존 승인 완료 건의 조회·승인 재확인은 유지한다. 자동 밴/삭제/환불은 하지 않는다.
- 결제 금액, 새로고침 횟수, 추천 거리·나이 우선순위 정책, 사진 URL 규칙, 번호 공개 48시간 규칙, 휴대폰 인증 구현은 이번 패치에서 바꾸지 않았다.

## 검증 결과

- 이번 변경만 배포 기준 커밋 `acfd7e4` 위 별도 작업 폴더에 적용해 검증. 기존 미반영 UI/결제 재시도/휴대폰 인증 작업은 제외.
- 지역·연령·추천·새로고침·프로필·가까운 이상형 회귀 테스트 **241개 통과**. 정상 저장, 부적격 저장/복구/수락 차단, 거절 유지, 잘못된 소유자/누락 데이터/DB 오류, KST 연도 경계 포함.
- 최종 재검증은 알림/SMS 문구·차단·탈퇴·결제 실패 안내·인증 세션·프로필 DB 권한까지 확장해 **269개 통과, 실패/건너뜀 0건**. SQL 검증 도구 경로 누락으로 2개가 처음 실행되지 않았으나, 기존 독립 PGlite 설치 경로를 연결해 전체를 다시 실행하여 통과했다. 서비스 의존성/SQL은 변경하지 않았다.
- 실제 결제 API 함수에 테스트 DB/결제 경계를 주입해 일반 주문 생성, 플러스 승인, 결제 승인 및 재호출을 검증. 성인은 정상 승인되고 재호출은 결제 승인 1회 유지. 부적격이면 결제 요청/주문 생성/번호 승인 전에 차단.
- 프로덕션 빌드 및 타입 검사 통과(308개 페이지). 린트 0 오류, 기존 `<img>` 경고 2건. 기존 middleware/Browserslist 빌드 경고 유지.
- 별도 현재 작업 폴더의 전화 인증/연락처 공개 회귀 **27개 통과**. 해당 검증에는 다른 작업의 미반영 전화 인증 변경이 포함되므로 이번 패치만의 배포 증명과 구분한다. 이번 패치는 해당 인증 파일을 수정하지 않는다.
- 배포 대상만 있는 분리 작업 폴더에서도 위 테스트의 `checkContacts` 함수만 별도로 실행해 **번호 공개 10개 시나리오 통과**: 양쪽 당사자 원문 표시, 48시간 이내 유지, 미결제/취소 미공개, 레거시 카드 번호 대체, 차단/비로그인/다른 사용자 차단, DB 오류 시 비공개.
- 운영 추천 데이터를 최신 코드로 읽기 전용 재현: 수도권 남성/영남 남성/호남 여성 3개 집단 모두 성공. 기본 추천과 다음 새로고침 모두 근거리+연령 적합 10명. 다음 목록 중복은 각각 0/2/8명으로, 풀이 적을 때 일부 중복되는 기존 정책은 유지.
- 지역 정밀도 비교: 시·군·구 수준 인식 788→1,090건(302건 개선), 정밀도 하락 0건. 모호하거나 복수 지역인 입력의 기존 정책은 변경하지 않았다.
