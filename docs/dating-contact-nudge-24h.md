## 변경

- 쌍방 수락 후 미결제 상태에서 한마디 보내기를 여는 시간을 48시간에서 24시간으로 단축한다.
- 앱/API는 공통 시간 상수를 사용하고, DB 삽입 검증도 같은 24시간을 적용한다.
- 기존 매칭에도 원래 쌍방 수락 시각을 기준으로 적용한다. 24~48시간 사이이며 아직 문구를 보내지 않은 매칭도 배포/DB 적용 후 목록을 다시 불러오면 대상이 된다.
- 자동 발송이 아니다. 회원이 기존 정해진 문구를 선택해 전송해야 알림/이메일이 전송된다.
- 동일 매칭에서 발신자별 1회 제한, 차단 확인, 참여자 확인, 결제/취소 상태 검사, 한글/이메일 문구는 유지한다.
- 번호 공개·매칭 취소의 48시간 규칙, 후보 새로고침, 결제 금액, 기존 발송 기록은 변경하지 않는다.

## 적용 순서

1. 기존 운영 DB에는 `supabase/sql/dating_1on1_contact_nudge_24h.sql` 실행. 기존 검증 함수의 시간 조건만 바꾸며 데이터 갱신/삭제/발송은 없다. 중복 실행 가능.
2. 이후 코드 배포. DB를 먼저 바꿔도 구버전 API는 48시간까지 계속 제한하므로 조기 발송이 일어나지 않는다.
3. 기존 회원은 매칭 목록을 다시 조회하면 새 조건을 적용받는다. 열어 둔 화면을 정확히 24시간 시점에 자동 갱신하는 변경은 아니다.

코드만 먼저 배포하고 SQL을 누락하면 24~48시간 매칭의 버튼은 떠도 DB가 발송을 거절한다. 따라서 두 가지가 모두 적용되기 전에는 운영 적용 완료라고 안내하지 않는다.
